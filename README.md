# RamadanFit (Flutter)

Squelette d'application Flutter pour accompagner un sportif pendant le Ramadan :

- Plan repas (suhoor/iftar)
- Hydratation
- Entraînements adaptés
- Suivi de progression

## Lancer le projet

```bash
flutter pub get
flutter run
```

## Structure

```text
lib/
  app.dart
  main.dart
  core/
    app_theme.dart
  features/
    home/
      home_page.dart
    meal_plan/
      meal_plan_page.dart
    hydration/
      hydration_page.dart
    workouts/
      workouts_page.dart
    progress/
      progress_page.dart
```
